# Getting help

- **Getting started with the Make PPTX skills:** read the [Get started guide](https://github.com/MaximeRumpler/Make_PPTX/blob/main/docs/get-started.md). It covers installation for each assistant and the most common problems.
- **Something did not work:** open an issue in the repository concerned. Say which assistant you use (Claude.ai, Claude Code, Codex, Cursor, Copilot, Gemini CLI…), your operating system, what you asked and what happened.
- **A question or an idea:** use the Discussions tab of the repository when it is enabled.
- **A security problem:** see [SECURITY.md](SECURITY.md); do not open a public issue.
