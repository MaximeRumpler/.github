# Contributing

Thanks for your interest. Each repository may have its own `CONTRIBUTING.md` with project-specific steps (tests, generated files, style rules); read it first if it exists. Otherwise:

1. **Open an issue first** for anything larger than a typo, so we agree on the change before you spend time on it.
2. **Keep pull requests small and focused.** Describe the problem, what changed, and how you checked it.
3. **Write in English** in code, comments, commits and documentation.
4. **Add or update a test** when you change behaviour, if the repository has tests.
5. **Be kind in reviews.** The [code of conduct](CODE_OF_CONDUCT.md) applies everywhere.

By contributing you agree that your contribution is licensed under the licence of the repository you contribute to.
