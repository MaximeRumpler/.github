# Community health files

Default community files for the public repositories of [MaximeRumpler](https://github.com/MaximeRumpler), including the [Make PPTX](https://github.com/MaximeRumpler/Make_PPTX) skills.

GitHub shows these files in any public repository of this account that does not have its own copy. A repository's own file always takes precedence.

| File | Purpose |
|---|---|
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 and how to report a problem |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to propose a change |
| [SECURITY.md](SECURITY.md) | How to report a vulnerability privately |
| [SUPPORT.md](SUPPORT.md) | Where to ask for help |
| [.github/](.github/) | Issue forms ("It didn't work", "Idea") and the pull request template |
